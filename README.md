# Build, tests, and coverage

Build the program with GCC and Make:

```sh
make program
```

Run the automated backend unit tests with:

```sh
make test_backend
```

Run the webstoretest.txt:

```sh
make text
```

Run back end with valgrind:

```sh
make valgrind_backend
```


To run the program there is no need for external files or input files in the terminal.

Line and branch coverage was measured with GCC's `gcov` compiling with
`--coverage -O0`. The measurement measure the backend CUnit suite (11 tests, 97 assertions).

# Using the program

After building, start the interactive program with:

```sh
./program
```

After building, running the program with valgrind:

```sh
make run
```

The program displays a menu for merchandise, inventory, and shopping-cart
operations. No input or data files are required: each run starts with an empty
in-memory database, which is discarded when the program exits.
